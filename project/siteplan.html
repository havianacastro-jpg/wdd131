Bean & Brew

Website Planning Document

Site Name

Name: Bean & Brew

Description: Este nombre fue seleccionado porque evoca la esencia directa del café de especialidad (el grano "bean" y la infusión "brew"). Representa un espacio acogedor enfocado en descubrir, calificar y reseñar las mejores cafeterías locales.

Optional domain availability: bean-and-brew-guide.org

Site Purpose

El sitio web funciona como una guía integral para los amantes del café local. Proporciona reseñas detalladas, calificaciones de calidad, información sobre tipos de granos de café, ubicaciones geográficas y un formulario interactivo para que los visitantes envíen sus propias recomendaciones y experiencias.

Scenarios

Preguntas clave que los usuarios de nuestro público objetivo buscarán resolver en el sitio:

  • ¿Cuáles son las cafeterías mejor calificada en la zona centro para trabajar o estudiar?
  • ¿Cómo puedo enviar la reseña de una nueva cafetería que acabo de descubrir?

Color Schema

Los colores seleccionados reflejan la calidez, la tierra y la cultura alrededor del café:

Principal

Marrón Café Oscuro (#4A3B32): Utilizado para el encabezado principal, pie de página y títulos destacados.

Secundario

Café Claro (#D4A373): Utilizado para bordes, acentos visuales y líneas divisorias.

Acento

Crema Suave (#FAEDCD): Utilizado para fondos de tarjetas y destacar bloques de contenido.

Typography

Se han seleccionado dos fuentes para mantener la legibilidad y la elegancia del sitio:

  • Heading Font (Merriweather): Utilizada en todos los títulos principales (h1, h2, h3) para dar una sensación clásica y editorial.
  • Body Font (Roboto): Utilizada en los párrafos, listas y textos generales para asegurar una lectura limpia y moderna.
